# RDS Digital Website Redesign

A modern, responsive homepage redesign for RDS Digital.

## Features
- Responsive design for desktop, tablet, and mobile
- Smooth animations and hover effects
- Services and portfolio sections
- Animated statistics section
- Contact form and Google Maps integration

## Technologies Used

- CSS3
- JavaScript
